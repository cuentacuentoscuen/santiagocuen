# Santiago Cuen Arte

Sitio web de portafolio artístico de Santiago Cuen.

## Despliegue

Este repositorio contiene el sitio estático listo para desplegarse en Vercel.

- `index.html` — entrada principal de la SPA (React)
- `assets/` — CSS y JS compilados
- `portfolio/` — imágenes del portafolio organizadas por categoría
- `artist/` — fotografía del artista
- `estudio/` — imágenes del estudio
